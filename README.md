## Caso de estudio: Biblioteca UNTEC

### Descripción

El proyecto consistió en desarrollar una aplicación de biblioteca utilizando Java y una base de datos MySQL.

### Desafío principal

El mayor desafío fue crear la estructura del proyecto y conseguir que la aplicación se conectara correctamente con la base de datos.

### Solución propuesta

Organicé el proyecto en diferentes paquetes, creé las clases necesarias y configuré la conexión hasta obtener el mensaje de conexión exitosa.

### Herramientas utilizadas

Java, Eclipse, MySQL Workbench, Java EE y Tomcat.

### Principales aprendizajes

Aprendí a conectar una aplicación con una base de datos, corregir errores y comprobar su funcionamiento antes de realizar la entrega.

### Resultado obtenido

La aplicación logró conectarse correctamente con la base de datos `biblioteca_untec` y fue ejecutada utilizando Tomcat.
